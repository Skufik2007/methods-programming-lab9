## 4. Доработка по замечаниям ревью

Запрос: «Сделай правки по замечаниям».

| Замечание ревью | Решение |
|---|---|
| Нет write deadline в TCP-сервере | Добавлен `SetWriteDeadline` перед каждой записью ответа. |
| `os.ErrDeadlineExceeded` логируется как ошибка | Отдельная ветка: «закрыто по тайм-ауту простоя». |
| Игнорируется результат `SetReadDeadline` | Ошибка обрабатывается. |
| `TcpClient.close()` не вычитывает ответ на `quit` | **Не принято**: `request()` уже читает ответ. Добавлен поясняющий комментарий. |
| `build_go` по mtime «протухнет» с общими пакетами | Теперь всегда вызывается `go build`, кэш Go сам решает, что пересобирать. |
| `Vec<bool>` на 1e9 ≈ 1 ГБ | Битовое решето по нечётным числам (~60 МБ), подсчёт через popcount. Ускорение относительно Python выросло с ×2.5 до ×8.9. |
| Граничные случаи решета не прокомментированы | Комментарии и тесты для 0, 1, 2, 3, 4, 9. |
| Нет проверки версии тега | Job `check-version` в `release.yml` сверяет тег с `pyproject.toml` и `Cargo.toml`. |
| Колёса собираются на main зря | **Оставлено осознанно**: это проверка, что релиз соберётся до тега. Причина записана в комментарии в workflow. |
| `publish = false` в Cargo.toml | Добавлен комментарий: флаг относится только к crates.io. |
| Нет комментария, почему нет гонки в `c[i]` | Добавлен. Канал сегментов сделан буферизованным. |
| `elapsed_ms` | В README уточнено, что это чистое время вычисления без ожидания семафора. |
| Ошибки калькулятора в stdout | Оставлено намеренно, обоснование добавлено в README. |
| «Мегакоммит» | Переписывать уже опубликованную историю с тегом не стали. Исправления по ревью разбиты на отдельные коммиты по темам. |

Дополнительно агент добавил в CI линтеры (`gofmt`, `go vet`, `rustfmt`, `clippy -D warnings`) и проверил, что все тесты проходят локально и на GitHub.
